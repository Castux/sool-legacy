# sool (2011–2013)

My "ideal" programming language: its design, discussed at length in a series of devlog posts (`doc/`), and its compiler, first prototyped in Lua (`compiler/`), then started again in C++ (`markII/`, `mark2/`).

It never got finished. A later attempt, in C#, is [Castux/sool](https://github.com/Castux/sool).

It was imported from Launchpad (Bazaar) in 2026, with its full history.
